Hardware Recommendations

Choose the right hardware for your needs and budget

Raspberry Pi 4/5 (4-8GB)

~$60-120

  • Perfect for: Pi-hole, Home Assistant, lightweight services
  • Low power consumption (5-15W)
  • Limited RAM for heavy containers
  • ARM architecture (some images unavailable)

Used Thin Client (Dell Wyse, HP t6xx)

~$50-100

  • x86_64 architecture - runs everything
  • Low power (10-20W idle)
  • Usually 4-8GB RAM, 64-128GB SSD
  • Great value for entry home lab

Old Laptop

Free - $100

  • Built-in UPS (battery backup)
  • Screen/keyboard for local access
  • WiFi + Ethernet
  • Remove battery for 24/7 operation

Intel NUC / Mini PC (i5/i7 8th-12th gen)

~$150-350

  • Excellent performance per watt
  • Quick Sync for hardware transcoding (Jellyfin/Plex)
  • Supports 32-64GB RAM
  • Small footprint, quiet

Custom Mini-ITX Build

~$300-500

  • Full control over components
  • Multiple drive bays for NAS
  • Can add GPU for transcoding/AI
  • Easier to upgrade/repair

Used Enterprise Micro Server (Lenovo ThinkCentre, Dell OptiPlex Micro)

~$100-200

  • Enterprise build quality
  • Intel i5/i7, 16-32GB RAM common
  • Very cheap on secondary market
  • Low profile, standard parts

Used Enterprise Rack Server (Dell R720/R730, HP DL380)

~$300-600

  • Dual Xeon, 128GB+ RAM, 8+ drive bays
  • IPMI/iDRAC for remote management
  • Redundant PSUs, ECC RAM
  • Loud! Needs separate room/rack

Modern Consumer Build (Ryzen 7/9, i7/i9)

~$600-1000+

  • Best single-thread performance
  • Quick Sync / NVENC for transcoding
  • Quiet, efficient, modern instruction sets
  • Great for VMs + containers + AI workloads

Synology / QNAP NAS

~$400-1000+ (diskless)

  • Turnkey solution with great UI
  • Docker support (Container Manager)
  • RAID management, snapshots, apps
  • Premium price for convenience

Networking Essentials

Understand the networking concepts you'll need for a reliable home lab

VLANs & Network Segmentation

Separate IoT, management, and trusted devices for security. Configure on managed switches and router.

Learn More →

DNS & Local Domains

Set up Pi-hole or AdGuard Home for ad-blocking and local DNS. Use .local or custom TLD for services.

Learn More →

Reverse Proxy

Single entry point for all services. Automatic HTTPS with Let's Encrypt. Path-based or subdomain routing.

Learn More →

VPN / Remote Access

Tailscale (easiest), WireGuard (performance), or OpenVPN. Access services securely from anywhere.

Learn More →

Firewall Rules

Default deny inbound. Allow only what's needed. Use UFW, firewalld, or OPNsense/pfSense for advanced rules.

Learn More →

Security Hardening

Fail2ban, SSH keys only, 2FA on everything, regular updates, minimal attack surface.
