Remote Access (VPN)

Securely access your home lab from anywhere using Tailscale, WireGuard, or OpenVPN. Compare options and set up zero-trust remote access.

Beginner ~25 min read Updated 2026

Why Not Just Port Forward?

Never expose services directly to the internet. Port forwarding exposes your services to the entire internet - bots, scanners, and attackers. Even with authentication, vulnerabilities in the service itself can be exploited.

Risks of Port Forwarding

  • Constant scanning - Your IP is probed within minutes of being online
  • Zero-day exploits - Services like Jellyfin, Nextcloud, etc. have had RCE vulnerabilities
  • Brute force attacks - Automated login attempts 24/7
  • No encryption guarantee - Some services use HTTP internally
  • Single point of failure - One compromised service = full network access

Benefits of VPN Access

  • Zero trust - Services only accessible via authenticated, encrypted tunnel
  • No open ports - Router firewall stays closed
  • Encrypted traffic - All traffic encrypted end-to-end
  • Device authorization - Only approved devices can connect
  • Network segmentation - Access only what you need
  • Works behind CGNAT - No public IP required (Tailscale/WireGuard)

🏆 Recommendation

Start with Tailscale - it's free for personal use (up to 100 devices), works behind any NAT, has excellent apps, and takes 5 minutes to set up. Migrate to Headscale later if you want full self-hosted control.

Tailscale (Easiest - Recommended)

How It Works

Tailscale creates a mesh WireGuard network between your devices. It uses a coordination server (run by Tailscale) for key exchange and NAT traversal, but all data flows directly peer-to-peer (or via DERP relays).

Quick Start

  1. Create account at tailscale.com (GitHub, Google, Microsoft, or email)
  2. Install on your server: 
    curl -fsSL https://tailscale.com/install.sh | sh
  3. Authenticate: 
    sudo tailscale up
  4. Install Tailscale app on your phone/laptop and sign in
  5. Done! Access services at http://server-hostname:port or http://100.x.y.z:port

Subnet Router (Access All LAN Devices)

Make your server a gateway to your entire home network:

# Enable IP forwarding
echo 'net.ipv4.ip_forward = 1' | sudo tee /etc/sysctl.d/99-tailscale.conf
echo 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

# Advertise your LAN subnet (e.g., 192.168.1.0/24)
sudo tailscale up --advertise-routes=192.168.1.0/24

# In Tailscale admin console: Machines → ... → Edit route settings → Approve routes

Exit Node (Route All Traffic Through Home)

# On server: enable exit node
sudo tailscale up --advertise-exit-node

# On client: use exit node
tailscale up --exit-node=server-hostname
# Or select in Tailscale app: "Route all traffic through server-hostname"

MagicDNS (Automatic Hostnames)

Enable in admin console: DNS → MagicDNS. Access services via http://jellyfin.your-tailnet.ts.net or just http://jellyfin.

ACL (Access Control)

Restrict which devices can access which services in admin console → Access Controls:

{
  "groups": {
    "group:admin": ["user@github"],
    "group:family": ["user2@github", "user3@google"]
  },
  "hosts": {
    "jellyfin": "100.x.y.z:8096",
    "nextcloud": "100.x.y.z:80"
  },
  "acls": [
    {"action": "accept", "src": ["group:admin"], "dst": ["*:*"]},
    {"action": "accept", "src": ["group:family"], "dst": ["jellyfin:8096", "nextcloud:80"]},
    {"action": "deny", "src": ["group:family"], "dst": ["*:*"]}
  ]
}

WireGuard (High Performance)

Why WireGuard?

  • Kernel-level (Linux 5.6+) - fastest performance
    • Minimal codebase (~4000 lines) - auditable
  • Modern cryptography (ChaCha20, Poly1305, Curve25519, BLAKE2s)
  • No handshake latency - stateless
  • Roaming support - IP changes don't break connection

Server Setup (Docker)

version: '3.8'

services:
  wireguard:
    image: lscr.io/linuxserver/wireguard:latest
    container_name: wireguard
    cap_add:
      - NET_ADMIN
      - SYS_MODULE
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/New_York
      - SERVERURL=auto  # Or yourdomain.com
      - SERVERPORT=51820
      - PEERS=phone,laptop,tablet  # Client names
      - PEERDNS=1.1.1.1,1.0.0.1    # DNS for clients
      - INTERNAL_SUBNET=10.13.13.0/24
      - ALLOWEDIPS=0.0.0.0/0,::/0  # Full tunnel (or 10.13.13.0/24 for split)
    volumes:
      - ./config:/config
      - /lib/modules:/lib/modules:ro
    ports:
      - "51820:51820/udp"
    restart: unless-stopped
    sysctls:
      - net.ipv4.conf.all.src_valid_mark=1

Client Configuration

After starting, QR codes and configs are in ./config/peer_*/:

# View QR code for phone
cat ./config/peer_phone/peer_phone.png | qrencode -t ansiutf8

# Or install qrencode and run:
qrencode -t ansiutf8 < ./config/peer_phone/peer_phone.conf

Manual Config (No Docker)

# Install
sudo apt install -y wireguard wireguard-tools

# Generate keys
wg genkey | tee server_private.key | wg pubkey > server_public.key
wg genkey | tee client_private.key | wg pubkey > client_public.key

# Server config: /etc/wireguard/wg0.conf
[Interface]
Address = 10.13.13.1/24
PrivateKey = 
ListenPort = 51820
PostUp = iptables -A FORWARD -i %i -j ACCEPT; iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
PostDown = iptables -D FORWARD -i %i -j ACCEPT; iptables -t nat -D POSTROUTING -o eth0 -j MASQUERADE

[Peer]
PublicKey = 
AllowedIPs = 10.13.13.2/32

# Client config
[Interface]
Address = 10.13.13.2/24
PrivateKey = 
DNS = 1.1.1.1

[Peer]
PublicKey = 
Endpoint = yourdomain.com:51820
AllowedIPs = 10.13.13.0/24, 192.168.1.0/24
PersistentKeepalive = 25

Manage with WG-Easy (Web UI)

version: '3.8'
services:
  wg-easy:
    image: weejewel/wg-easy:latest
    container_name: wg-easy
    cap_add:
      - NET_ADMIN
      - SYS_MODULE
    environment:
      - WG_HOST=yourdomain.com
      - PASSWORD=your-admin-password
      - WG_PORT=51820
      - WG_DEFAULT_ADDRESS=10.13.13.x
      - WG_DEFAULT_DNS=1.1.1.1
    volumes:
      - ./data:/etc/wireguard
    ports:
      - "51820:51820/udp"
      - "51821:51821/tcp"  # Web UI
    restart: unless-stopped

OpenVPN (Traditional)

When to Use OpenVPN

  • Corporate/enterprise requirements
  • Need TCP fallback (some networks block UDP)
  • Legacy client support
  • Compliance requirements

Docker Setup (OpenVPN-AS)

version: '3.8'
services:
  openvpn-as:
    image: linuxserver/openvpn-as:latest
    container_name: openvpn-as
    cap_add:
      - NET_ADMIN
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/New_York
      - INTERFACE=eth0
    volumes:
      - ./config:/config
    ports:
      - "943:943/tcp"   # Admin UI
      - "9443:9443/tcp" # Client web UI
      - "1194:1194/udp" # OpenVPN
    restart: unless-stopped

Access Admin UI

Open https://yourdomain.com:943/admin (accept self-signed cert warning). Default user: openvpn, password from logs.

Headscale (Self-Hosted Tailscale)

Headscale is an open-source implementation of the Tailscale coordination server. Use Tailscale clients with your own control plane.

Why Headscale?

  • Full data sovereignty - no third-party coordination server
  • Free unlimited devices (vs Tailscale's 100 device limit)
  • Same great Tailscale clients
  • Supports most Tailscale features

Docker Compose

version: '3.8'

services:
  headscale:
    image: headscale/headscale:latest
    container_name: headscale
    restart: unless-stopped
    volumes:
      - ./data:/var/lib/headscale
      - ./config:/etc/headscale
    ports:
      - "8080:8080"
    environment:
      - HEADSCALE_SERVER_URL=https://headscale.yourdomain.com
      - HEADSCALE_METRICS_LISTEN_ADDR=0.0.0.0:9090
      - HEADSCALE_GRPC_LISTEN_ADDR=0.0.0.0:50443
      - HEADSCALE_GRPC_ALLOW_INSECURE=false

  headscale-ui:
    image: ghcr.io/gurucomputing/headscale-ui:latest
    container_name: headscale-ui
    restart: unless-stopped
    ports:
      - "8081:80"
    environment:
      - HEADSCALE_URL=https://headscale.yourdomain.com

  derp:
    image: fredliang/derper:latest
    container_name: derp
    restart: unless-stopped
    ports:
      - "3478:3478/udp"  # STUN
      - "443:443"        # DERP HTTPS
    environment:
      - DERP_SERVER_ADDR=:443
      - DERP_STUN_ADDR=:3478
      - DERP_VERIFY_CLIENTS=true

Configuration (config.yaml)

# config/config.yaml
server_url: https://headscale.yourdomain.com
listen_addr: 0.0.0.0:8080
metrics_listen_addr: 0.0.0.0:9090
grpc_listen_addr: 0.0.0.0:50443
grpc_allow_insecure: false

db_type: sqlite3
db_path: /var/lib/headscale/db.sqlite3

derp:
  urls:
    - https://derp.yourdomain.com
  paths:
    - /derp
  auto_update_enabled: true
  update_frequency: 24h

acl_policy_path: "/etc/headscale/policy.hujson"
log_level: info

tls_letsencrypt_hostname: headscale.yourdomain.com
tls_letsencrypt_listen: ":443"
tls_letsencrypt_cache_dir: "/var/lib/headscale/cache"

policy:
  mode: file

Client Setup

# On client devices, use Tailscale CLI with custom login server
tailscale up --login-server=https://headscale.yourdomain.com

# Or set via environment
export TS_LOGIN_SERVER=https://headscale.yourdomain.com
tailscale up

# For GUI apps, enter login server in settings

Split Tunneling & DNS

Split Tunnel (Only Home Lab Traffic)

Route only home lab traffic through VPN, rest goes direct:

# Tailscale
tailscale up --advertise-routes=192.168.1.0/24 --accept-routes=false

# WireGuard client config
AllowedIPs = 10.13.13.0/24, 192.168.1.0/24  # Only VPN + LAN

# OpenVPN client config
pull-filter ignore redirect-gateway
route 192.168.1.0 255.255.255.0

Full Tunnel (All Traffic Through Home)

Use your home internet connection for everything:

# Tailscale
tailscale up --exit-node=server-hostname

# WireGuard client config
AllowedIPs = 0.0.0.0/0, ::/0

# OpenVPN client config (default)
# redirect-gateway def1

MagicDNS / Local DNS

# Tailscale MagicDNS - automatic
# Enable in admin console → DNS → MagicDNS

# Manual DNS with WireGuard/OpenVPN
# Run AdGuard Home or Pi-hole on VPN IP
# Push DNS to clients:
# WireGuard: PEERDNS=10.13.13.1
# OpenVPN: push "dhcp-option DNS 10.13.13.1"

Mobile & Device Setup

iOS / iPadOS

  • Tailscale: App Store → Tailscale → Sign in
  • WireGuard: App Store → WireGuard → Scan QR / Import config
  • OpenVPN: App Store → OpenVPN Connect → Import .ovpn

Android

  • Tailscale: Play Store / F-Droid → Tailscale
  • WireGuard: Play Store / F-Droid → WireGuard
  • OpenVPN: Play Store / F-Droid → OpenVPN for Android

Always-On VPN (Android)

Settings → Network & Internet → VPN → Gear icon → "Always-on VPN" + "Block connections without VPN"

macOS / Windows / Linux

  • Tailscale: Download from tailscale.com/download
  • WireGuard: Official clients or WireGuard tools
  • OpenVPN: OpenVPN Connect, Tunnelblick (macOS), NetworkManager (Linux)

Router-Level VPN (All Devices)

Run VPN client on router for devices that can't run VPN apps (Smart TV, IoT, consoles):

  • OpenWrt: WireGuard/OpenVPN packages
  • GL.iNet routers: Built-in WireGuard/OpenVPN/Tailscale
  • ASUS/Merlin: Built-in OpenVPN/WireGuard client
  • Ubiquiti: WireGuard via CLI/config.gateway.json
