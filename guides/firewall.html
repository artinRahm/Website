Firewall Rules

Default deny inbound. Allow only what's needed. Use UFW, firewalld, or OPNsense/pfSense for advanced rules. Layer 7 filtering with CrowdSec.

Intermediate ~25 min read Updated 2026

Firewall Fundamentals

Default Deny Policy

Golden Rule: Block everything by default. Explicitly allow only required traffic. This applies at every layer: network, host, application.

Rule Processing Order

  1. First match wins - Rules evaluated top to bottom
  2. Stateful inspection - Return traffic for allowed connections auto-permitted
  3. Implicit deny - Last rule blocks anything not matched

Where to Filter

Layer Tool Scope Best For
Network Edge OPNsense, pfSense, Router All traffic entering/leaving LAN VLAN isolation, WAN rules, GeoIP
Host UFW, firewalld, nftables Single server/container host Service ports, Docker isolation
Container Docker networks, CNI plugins Inter-container traffic Microservice segmentation
Application CrowdSec, ModSecurity, Authelia HTTP/L7 traffic WAF, bot detection, auth

Edge Firewall (OPNsense / pfSense)

WAN Interface Rules

# Default: Block all inbound (implicit)
# Explicit allows (top to bottom):

# 1. Allow established/related (auto-handled by state table)

# 2. VPN Access (WireGuard/Tailscale)
Pass  UDP  WAN  *  →  WAN_IP  51820  (WireGuard)
Pass  TCP  WAN  *  →  WAN_IP  443    (Tailscale/derper)

# 3. Cloudflare Tunnel (outbound only - no inbound ports!)
# No WAN rules needed - tunnel initiates outbound

# 4. Port Forwards (if absolutely necessary)
# DNAT: WAN:443 → ReverseProxy:443
# Associated filter rule auto-created on WAN

# 5. Block known bad (pfBlockerNG / Aliases)
Block TCP/UDP WAN * → WAN_IP * (GeoIP: CN, RU, KP, etc.)
Block TCP/UDP WAN * → WAN_IP * (Spamhaus DROP, Emerging Threats)

LAN/VLAN Interface Rules (Per Interface)

# MGMT Interface (10.10.10.0/24)
Pass  *  MGMT_net  →  *              # Full access
Block *  MGMT_net  →  RFC1918        # Except other LANs (optional)

# SERVERS Interface (10.10.10.0/24)
Pass  TCP  SERVERS_net → TRUSTED_net  80,443,8096,8123,9000,3001  # Service ports
Pass  UDP  SERVERS_net → DNS_IP       53                           # DNS
Pass  *    SERVERS_net → VPN_net      *                            # VPN access
Block *    SERVERS_net → IOT_net      *                            # No IoT
Block *    SERVERS_net → GUEST_net    *                            # No Guest

# TRUSTED Interface (10.10.20.0/24)
Pass  *  TRUSTED_net → SERVERS_net    *       # Access services
Pass  *  TRUSTED_net → MGMT_net       22,443  # Admin access
Pass  *  TRUSTED_net → VPN_net        *       # VPN access
Pass  *  TRUSTED_net → WAN            *       # Internet
Block *  TRUSTED_net → IOT_net        *       # No direct IoT
Block *  TRUSTED_net → GUEST_net      *       # No Guest

# IOT Interface (10.10.30.0/24)
Pass  UDP  IOT_net   → DNS_IP         53      # DNS only
Pass  UDP  IOT_net   → NTP_IP         123     # Time sync
Pass  TCP  IOT_net   → UPDATE_SERVERS 443     # Specific update servers
Block *    IOT_net   → RFC1918        *       # No LAN access
Pass  *    IOT_net   → WAN            *       # Internet (restricted)

# GUEST Interface (10.10.40.0/24)
Pass  *  GUEST_net → WAN              *       # Internet only
Block *  GUEST_net → RFC1918          *       # No LAN access

# VPN Interface (10.10.50.0/24)
Pass  *  VPN_net   → MGMT_net         *       # Full management
Pass  *  VPN_net   → SERVERS_net      *       # All services
Pass  *  VPN_net   → TRUSTED_net      *       # Trusted devices

Floating Rules (Advanced)

  • Match on any interface - For rules applying to multiple VLANs
  • Quick - Stop processing on match (like normal rules)
  • Direction: in/out - Control flow direction
  • Use for: QoS, VPN kill-switch, logging suspicious outbound

Host Firewall (UFW / firewalld)

UFW (Ubuntu/Debian)

# Reset to defaults
sudo ufw reset

# Default policies
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw default deny routed

# Allow SSH (adjust for your MGMT network)
sudo ufw allow from 10.10.10.0/24 to any port 22 proto tcp comment 'SSH from MGMT'

# Allow Docker host management (if needed)
sudo ufw allow from 10.10.10.0/24 to any port 2376 proto tcp comment 'Docker TLS'

# Allow specific service ports from TRUSTED
sudo ufw allow from 10.10.20.0/24 to any port 8096 proto tcp comment 'Jellyfin'
sudo ufw allow from 10.10.20.0/24 to any port 8123 proto tcp comment 'Home Assistant'
sudo ufw allow from 10.10.20.0/24 to any port 9000 proto tcp comment 'Portainer'

# Allow inter-host communication (cluster)
sudo ufw allow from 10.10.10.0/24 to any port 7946 proto tcp comment 'Serf LAN'
sudo ufw allow from 10.10.10.0/24 to any port 7946 proto udp comment 'Serf WAN'
sudo ufw allow from 10.10.10.0/24 to any port 4789 proto udp comment 'VXLAN'

# Enable logging
sudo ufw logging medium

# Enable
sudo ufw enable

# Status
sudo ufw status verbose
sudo ufw status numbered  # For deleting rules

firewalld (RHEL/Fedora/Rocky)

# Zones: drop, block, public, external, internal, trusted, home, work
# Use 'internal' for LAN, 'external' for WAN

# Set default zone for interface
sudo firewall-cmd --permanent --zone=internal --change-interface=eth0
sudo firewall-cmd --permanent --zone=external --change-interface=eth1

# Internal zone (LAN) - allow specific services
sudo firewall-cmd --permanent --zone=internal --add-service=ssh
sudo firewall-cmd --permanent --zone=internal --add-source=10.10.10.0/24
sudo firewall-cmd --permanent --zone=internal --add-source=10.10.20.0/24

# Rich rules for specific ports
sudo firewall-cmd --permanent --zone=internal \
  --add-rich-rule='rule family=ipv4 source address=10.10.20.0/24 port port=8096 protocol=tcp accept'

# Docker zone (if using firewalld with Docker)
sudo firewall-cmd --permanent --zone=trusted --add-interface=docker0

# Reload
sudo firewall-cmd --reload

# List rules
sudo firewall-cmd --list-all-zones

nftables (Modern, Unified)

# /etc/nftables.conf
#!/usr/sbin/nft -f

flush ruleset

table inet filter {
    chain input {
        type filter hook input priority 0; policy drop;

        # Allow loopback
        iif "lo" accept

        # Allow established/related
        ct state established,related accept

        # ICMP
        ip protocol icmp accept
        ip6 protocol icmpv6 accept

        # SSH from MGMT only
        ip saddr 10.10.10.0/24 tcp dport 22 accept

        # Services from TRUSTED
        ip saddr 10.10.20.0/24 tcp dport { 8096, 8123, 9000, 3001 } accept

        # Docker/Container traffic
        iif "docker0" accept
        ip saddr 10.10.10.0/24 tcp dport 7946 accept
        ip saddr 10.10.10.0/24 udp dport 7946 accept
        ip saddr 10.10.10.0/24 udp dport 4789 accept

        # Log dropped
        limit rate 5/minute log prefix "DROP_INPUT: " flags all
    }

    chain forward {
        type filter hook forward priority 0; policy drop;

        # Container forwarding
        ct state established,related accept
        iif "docker0" oif "eth0" accept
        iif "eth0" oif "docker0" ct state related,established accept
    }

    chain output {
        type filter hook output priority 0; policy accept;
    }
}

Docker & Container Network Security

Docker Default Behavior

  • Docker creates `DOCKER-USER` chain (runs before DOCKER chain)
  • Published ports (`-p 8080:80`) bypass UFW - insert rules in `DOCKER-USER`
  • Bridge network: containers talk freely by default

Secure Docker with UFW

# /etc/ufw/after.rules (or create /etc/ufw/applications.d/docker)

# Don't delete the 'COMMIT' line
*filter
:DOCKER-USER - [0:0]

# Allow only from TRUSTED VLAN to published ports
-A DOCKER-USER -i ext_if ! -s 10.10.20.0/24 -j DROP

# Allow inter-container on user-defined networks
-A DOCKER-USER -i br-+ -o br-+ -j ACCEPT

# Block container → host (except specific)
-A DOCKER-USER -i br-+ -d 10.10.10.0/24 -j DROP

COMMIT

Rootless Docker / Podman

# Rootless uses slirp4netns / pasta - no NET_ADMIN needed

Application Layer Protection (CrowdSec)

What is CrowdSec?

Collaborative IPS. Analyzes logs, detects attacks, shares blocklists globally. Modern fail2ban replacement.

Docker Deployment

version: '3.8'

services:
  crowdsec:
    image: crowdsecurity/crowdsec:latest
    container_name: crowdsec
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - crowdsec-config:/etc/crowdsec
      - crowdsec-data:/var/lib/crowdsec
      - /var/log:/var/log:ro
      - /run/docker.sock:/run/docker.sock:ro
    environment:
      - COLLECTIONS=crowdsecurity/linux crowdsecurity/nginx crowdsecurity/traefik crowdsecurity/docker
    # Auto-remediation via bouncers (see below)

  # Bouncer: blocks at firewall level
  crowdsec-firewall-bouncer:
    image: crowdsecurity/crowdsec-firewall-bouncer:latest
    container_name: crowdsec-bouncer
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - crowdsec-config:/etc/crowdsec
      - /lib/modules:/lib/modules:ro
    environment:
      - CROWDSEC_AGENT_HOST=crowdsec
      - CROWDSEC_AGENT_PORT=8080
    cap_add:
      - NET_ADMIN
      - NET_RAW
    depends_on:
      - crowdsec

  # Bouncer: for Traefik/Nginx (L7 blocking)
  crowdsec-traefik-bouncer:
    image: crowdsecurity/crowdsec-traefik-bouncer:latest
    container_name: crowdsec-traefik-bouncer
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - crowdsec-config:/etc/crowdsec
    environment:
      - CROWDSEC_AGENT_HOST=crowdsec
      - CROWDSEC_AGENT_PORT=8080
      - MODE=traefik

networks:
  homelab:
    external: true

volumes:
  crowdsec-config:
  crowdsec-data:

GeoIP Blocking

OPNsense / pfSense (pfBlockerNG)

  1. Install pfBlockerNG-devel package
  2. Firewall → pfBlockerNG → IP → IPv4
  3. Enable "GeoIP" → Select countries to block
  4. Action: "Deny Inbound" / "Deny Outbound"
  5. Update frequency: Daily
  6. Apply → Creates alias + rules automatically

UFW + ipset (Linux Host)

# Install ipset
sudo apt install ipset iptables

# Create ipset for blocked countries
sudo ipset create geoip_block hash:net

# Download GeoIP lists (example: block CN, RU)
wget -qO- https://www.ipdeny.com/ipblocks/data/aggregated/cn-aggregated.zone | \
  while read ip; do sudo ipset add geoip_block $ip; done

wget -qO- https://www.ipdeny.com/ipblocks/data/aggregated/ru-aggregated.zone | \
  while read ip; do sudo ipset add geoip_block $ip; done

# Add UFW rule using ipset
sudo ufw insert 1 deny from any to any ipset geoip_block

# Persist ipset
sudo ipset save > /etc/ipset.conf
# Add to /etc/rc.local or systemd service to restore on boot

Monitoring & Logging

Log Collection

# Vector / Fluent Bit / Promtail for log shipping
# Example: Vector config to Loki
sources:
  firewall_logs:
    type: file
    include:
      - /var/log/ufw.log
      - /var/log/firewall.log

transforms:
  parse_firewall:
    type: remap
    inputs:
      - firewall_logs
    source: |
      . = parse_regex!(.message, r'\[UFW (\w+)\] .* SRC=(\S+) DST=(\S+) PROTO=(\S+) SPT=(\d+) DPT=(\d+)')
      .action = .[0]
      .src_ip = .[1]
      .dst_ip = .[2]
      .proto = .[3]
      .src_port = .[4]
      .dst_port = .[5]

sinks:
  loki:
    type: loki
    inputs:
      - parse_firewall
    endpoint: http://loki:3100/loki/api/v1/push
    labels:
      job: firewall
      host: "{{ hostname }}"

Troubleshooting

Can't access service after enabling firewall

# Check UFW status
sudo ufw status numbered

# Test connectivity
nc -zv 10.10.10.10 8096

# Check logs
sudo tail -f /var/log/ufw.log
journalctl -u firewalld -f

# Packet capture
sudo tcpdump -i eth0 host 10.10.20.50 and port 8096

Docker published ports bypass UFW

# Add rules to DOCKER-USER chain
iptables -I DOCKER-USER -i eth0 ! -s 10.10.20.0/24 -j DROP

# Or disable iptables in Docker daemon:
# /etc/docker/daemon.json
# { "iptables": false }
# Then manage all rules manually

VPN clients can't reach LAN

# Check VPN interface firewall rules
# Verify outbound NAT for VPN subnet
# Check routing: VPN clients need route to LAN subnets
# WireGuard: AllowedIPs = 10.10.0.0/16

CrowdSec not blocking

# Check bouncer logs
docker logs crowdsec-bouncer

# Verify decisions exist
cscli decisions list

# Check bouncer connected to agent
cscli machines list

Lockout recovery

# Console/serial access (always maintain!)
# UFW: ufw disable (from console)
# firewalld: firewall-cmd --panic-on (then --panic-off)
# nftables: nft flush ruleset
# OPNsense: Console menu → Option 4 (disable firewall)
