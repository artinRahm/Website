Authentik

Open-source identity provider. SSO, OAuth2/OIDC, SAML, LDAP. Secure all your services with one login. Multi-factor authentication, passwordless login, user provisioning.

Intermediate ~30 min read Updated 2026

Why Authentik?

Single Sign-On (SSO)

One login for all services. OAuth2/OIDC, SAML 2.0, LDAP. Works with any compatible app.

Multi-Factor Authentication

TOTP, WebAuthn/FIDO2 (YubiKey, TouchID), Email codes, SMS, Duo, Recovery codes.

Passwordless Login

WebAuthn passkeys, email magic links. Modern auth without passwords.

User Provisioning (SCIM)

Automatically create/update/delete users in connected apps. Supports SCIM 2.0.

Flexible Policies

Flow-based authentication. Custom policies per app, group, user. Risk-based auth, geo-blocking.

Self-Hosted & Free

No per-user fees. Run on your hardware. Open source (MIT). Active community.

Architecture Overview

Component Purpose Scaling
Server (Django) Core logic, API, admin UI, flows Horizontal (stateless)
Worker (Celery) Background tasks, email, LDAP sync Horizontal
PostgreSQL Primary data store Vertical, read replicas
Redis Cache, sessions, Celery broker Cluster mode
Proxy (optional) SSL termination, rate limiting Horizontal

Docker Deployment

Docker Compose (Production Ready)

version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    container_name: authentik-postgres
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - authentik-postgres:/var/lib/postgresql/data
    environment:
      - POSTGRES_PASSWORD_FILE=/run/secrets/postgres_password
      - POSTGRES_USER=authentik
      - POSTGRES_DB=authentik
    secrets:
      - postgres_password
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U authentik -d authentik"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    container_name: authentik-redis
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - authentik-redis:/data
    command: redis-server --maxmemory 256mb --maxmemory-policy allkeys-lru
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  server:
    image: ghcr.io/goauthentik/server:2024.12
    container_name: authentik-server
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - authentik-media:/media

      - AUTHENTIK_SECRET_KEY_FILE=/run/secrets/authentik_secret
      - AUTHENTIK_POSTGRES_HOST=postgres
      - AUTHENTIK_POSTGRES_USER=authentik
      - AUTHENTIK_POSTGRES_PASSWORD_FILE=/run/secrets/postgres_password
      - AUTHENTIK_POSTGRES_DB=authentik
      - AUTHENTIK_REDIS_HOST=redis
      - AUTHENTIK_REDIS_PORT=6379
      - AUTHENTIK_EMAIL_HOST=smtp.yourdomain.com
      - AUTHENTIK_EMAIL_PORT=587
      - AUTHENTIK_EMAIL_USERNAME_FILE=/run/secrets/email_user
      - AUTHENTIK_EMAIL_PASSWORD_FILE=/run/secrets/email_pass
      - AUTHENTIK_EMAIL_FROM=authentik@yourdomain.com
      - AUTHENTIK_ERROR_REPORTING_ENABLED=false
    secrets:
      - authentik_secret
      - postgres_password
      - email_user
      - email_pass
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    ports:
      - "9000:9000"
      - "9443:9443"

  worker:
    image: ghcr.io/goauthentik/server:2024.12
    container_name: authentik-worker
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - authentik-media:/media
      - authentik-templates:/templates
    environment:
      - AUTHENTIK_SECRET_KEY_FILE=/run/secrets/authentik_secret
      - AUTHENTIK_POSTGRES_HOST=postgres
      - AUTHENTIK_POSTGRES_USER=authentik
      - AUTHENTIK_POSTGRES_PASSWORD_FILE=/run/secrets/postgres_password
      - AUTHENTIK_POSTGRES_DB=authentik
      - AUTHENTIK_REDIS_HOST=redis
      - AUTHENTIK_REDIS_PORT=6379
    secrets:
      - authentik_secret
      - postgres_password
    depends_on:
      postgres:
        condition: service_healthy
      redis:
        condition: service_healthy
    command: worker
    deploy:
      resources:
        limits:
          memory: 512M

networks:
  homelab:
    external: true

volumes:
  authentik-postgres:
  authentik-redis:
  authentik-media:
  authentik-templates:

secrets:
  authentik_secret:
    file: ./secrets/authentik_secret.txt
  postgres_password:
    file: ./secrets/postgres_password.txt
  email_user:
    file: ./secrets/email_user.txt
  email_pass:
    file: ./secrets/email_pass.txt

Generate Secrets

mkdir -p ~/authentik/secrets && cd ~/authentik/secrets

# Secret key (64+ chars)
openssl rand -base64 48 > authentik_secret.txt

# Postgres password
openssl rand -base64 32 > postgres_password.txt

# Email credentials (if using SMTP)
echo "your-email@domain.com" > email_user.txt
echo "your-smtp-password" > email_pass.txt

# Secure permissions
chmod 600 *.txt

Deploy

cd ~/authentik
# Save as docker-compose.yml
docker compose up -d

# Check logs
docker compose logs -f server

Initial Setup

  1. Open https://your-server:9443/if/flow/initial-setup/
  2. Create superuser (email, username, password)
  3. Configure domain: auth.yourdomain.com
  4. Admin UI: https://auth.yourdomain.com/if/admin/

Core Concepts

Applications (Providers)

What you're protecting. Each app gets a provider configuration.

  • OAuth2/OpenID Connect: Modern apps (Nextcloud, Jellyfin, Grafana, etc.)
  • SAML 2.0: Enterprise apps (GitLab, Google Workspace, Office 365)
  • LDAP: Legacy apps, network devices, VPN
  • Proxy Provider: Protect apps that don't support SSO (forward auth)

Flows

Visual authentication pipelines. Drag-and-drop stages: login, MFA, consent, user write, etc.

  • Default flows: Login, Enrollment, Recovery, Unenrollment
  • Custom flows: Passwordless, conditional access, step-up auth
  • Stages: Authenticator validation, User login, Consent, Email, Captcha, etc.

Policies

Reusable logic attached to flows, stages, or providers.

  • Expression policies: Python-like expressions (user.groups.filter(name='admin').exists())
  • Reputation policies: IP reputation, geo-IP, failed attempts
  • Time policies: Time-based restrictions

Sources

Where users come from.

  • Local: Built-in user database
  • LDAP: Active Directory, OpenLDAP
  • OAuth: Google, GitHub, Microsoft, custom
  • SAML: External IdP

Common Service Integrations

Nextcloud (OIDC)

  1. Authentik: Applications → Providers → Create → OAuth2/OpenID Provider
  2. Name: "Nextcloud", Redirect URI: https://cloud.yourdomain.com/apps/oidc_login/
  3. Scopes: openid, profile, email, groups
  4. Note Client ID & Secret
  5. Nextcloud: Admin → Social Login → Add OIDC provider
  6. Enter Client ID, Secret, Discovery URL: https://auth.yourdomain.com/application/o/nextcloud/.well-known/openid-configuration

Grafana (OIDC)

# grafana.ini
[auth.generic_oauth]
enabled = true
name = Authentik
allow_sign_up = true
client_id = YOUR_CLIENT_ID
client_secret = YOUR_CLIENT_SECRET
scopes = openid profile email groups
auth_url = https://auth.yourdomain.com/application/o/grafana/authorize/
token_url = https://auth.yourdomain.com/application/o/grafana/token/
api_url = https://auth.yourdomain.com/application/o/grafana/userinfo/
role_attribute_path = contains(groups[*], 'grafana-admin') && 'Admin' || 'Viewer'

Jellyfin (OIDC)

Dashboard → Authentication → Add "OpenID Connect" → Enter issuer, client ID, secret.

Nginx Proxy Manager (Forward Auth)

Use Authentik Proxy Provider to protect any service without native SSO.

  1. Authentik: Applications → Providers → Create → Proxy Provider
  2. Forward Auth URL: https://auth.yourdomain.com/outpost.goauthentik.io/
  3. In NPM: Advanced → Custom Nginx Config:
location / {
    auth_request https://auth.yourdomain.com/outpost.goauthentik.io/;
    auth_request_set $user $upstream_http_x_authentik_user;
    auth_request_set $groups $upstream_http_x_authentik_groups;
    proxy_set_header X-Authentik-User $user;
    proxy_set_header X-Authentik-Groups $groups;
    # ... rest of proxy config
}

Home Assistant (OIDC)

# configuration.yaml
homeassistant:
  auth_providers:
    - type: openid
      client_id: YOUR_CLIENT_ID
      client_secret: YOUR_CLIENT_SECRET
      issuer_url: https://auth.yourdomain.com/application/o/home-assistant/
      redirect_uri: https://ha.yourdomain.com/auth/external/callback

Multi-Factor Authentication Setup

Enforce MFA for All Users

  1. Flows → Default Authentication Flow → Edit
  2. Add stage: "Authenticator Validation"
  3. Configure: Device classes → TOTP, WebAuthn
  4. Bind to "Authentication" stage
  5. Users will be prompted to enroll on first login

WebAuthn (Passkeys/YubiKey)

Settings → Authenticator Types → Enable WebAuthn. Configure Relying Party ID (your domain).

Recovery Codes

Users can generate recovery codes in their profile. Admins can view/reset in admin UI.

Backup & Restore

Backup Script

#!/bin/bash
# /usr/local/bin/backup-authentik.sh
set -euo pipefail

BACKUP_DIR="/mnt/backups/authentik"
DATE=$(date +%F_%H-%M)
RETENTION_DAYS=30

mkdir -p "$BACKUP_DIR"

# Database dump
docker exec authentik-postgres pg_dump -U authentik authentik | gzip > "$BACKUP_DIR/db_$DATE.sql.gz"

# Media files (certificates, custom templates)
docker run --rm \
  -v authentik-media:/media \
  -v "$BACKUP_DIR":/backup \
  alpine tar czf /backup/media_$DATE.tar.gz -C /media .

# Cleanup
find "$BACKUP_DIR" -type f -mtime +$RETENTION_DAYS -delete

echo "Authentik backup completed: $DATE"

Restore

# 1. Stop services
docker compose down

# 2. Restore database
gunzip -c db_2026-01-15_03-00.sql.gz | docker exec -i authentik-postgres psql -U authentik -d authentik

# 3. Restore media
docker run --rm \
  -v authentik-media:/media \
  -v /mnt/backups/authentik:/backup \
  alpine tar xzf /backup/media_2026-01-15_03-00.tar.gz -C /media

# 4. Start
docker compose up -d

Troubleshooting

Cannot access admin UI

# Check if server is healthy
docker logs authentik-server | tail -50

# Verify secret key matches in all containers
docker exec authentik-server cat /run/secrets/authentik_secret
docker exec authentik-worker cat /run/secrets/authentik_secret

OIDC redirect URI mismatch

# In Provider settings, ensure redirect URIs match EXACTLY:
# https://app.yourdomain.com/callback
# (no trailing slash if not in config)

Email not sending

# Check worker logs
docker logs authentik-worker | grep -i email

# Test SMTP from container
docker exec authentik-worker python -c "
import smtplib
s = smtplib.SMTP('smtp.yourdomain.com', 587)
s.starttls()
s.login('user', 'pass')
print('SMTP OK')
"

LDAP sync failing

# Check LDAP source configuration
# Test connection in Authentik UI: Sources → LDAP → Test Connection

# Common issues:
# - Wrong bind DN format (cn=admin,dc=example,dc=com)
# - TLS/SSL port (636 vs 389 + StartTLS)
# - Certificate verification (disable for self-signed)

Slow login / timeouts

# Check Redis memory
docker exec authentik-redis redis-cli INFO memory

# Increase worker count
# In docker-compose: deploy.replicas: 2 for worker

# Check PostgreSQL connections
docker exec authentik-postgres psql -U authentik -c "SELECT count(*) FROM pg_stat_activity;"
