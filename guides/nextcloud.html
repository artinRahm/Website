Nextcloud

Your own private cloud. File storage, calendar, contacts, office suite, and 200+ apps. Complete data ownership with end-to-end encryption.

Beginner ~25 min read Updated 2026

Why Nextcloud?

Data Ownership

Your files stay on your server. No corporate scanning, no AI training, no subscription fees for your own storage.

End-to-End Encryption

Optional client-side encryption means even you can't read files without the key. Perfect for sensitive documents.

Collaborative Editing

Collabora Online / OnlyOffice integration for real-time document, spreadsheet, and presentation editing.

Calendar & Contacts (CalDAV/CardDAV)

Sync calendars and contacts across all devices. Works with Apple Calendar, Google Calendar, Thunderbird, mobile phones.

200+ Apps Ecosystem

Notes, tasks, password manager, maps, talk (video calls), deck (kanban), forms, polls, and much more.

Cost Effective

Replace Dropbox ($120/yr), Google One ($100/yr), iCloud ($120/yr) with one-time hardware cost.

Hardware Requirements

Use Case CPU RAM Storage Notes
Personal (1-5 users) 2 cores 4 GB 50 GB + data Raspberry Pi 4, thin client
Family / Small Team (5-20) 4 cores 8-16 GB 100 GB + data Intel NUC, Mini PC
Team / Organization (20-100) 8+ cores 32+ GB SSD for DB + HDD for data Dedicated server, Redis caching
Enterprise (100+) 16+ cores 64+ GB Clustered storage Multiple app servers, load balancer
Tip: Put the database (MariaDB/PostgreSQL) and Redis cache on SSD/NVMe. Data directory can be on HDD. This dramatically improves UI responsiveness.

Docker Deployment

Docker Compose (Recommended: AIO - All-in-One)

The Nextcloud AIO (All-in-One) image includes Nextcloud, database, Redis, and Collabora Online in one container - easiest for beginners.

version: '3.8'

services:
  nextcloud-aio:
    image: nextcloud/all-in-one:latest
    container_name: nextcloud-aio
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - nextcloud-aio:/mnt/ncdata
      - /var/run/docker.sock:/var/run/docker.sock:ro
    ports:
      - "8080:8080"  # AIO management interface
    environment:
      - TZ=America/New_York
      - SKIP_DOMAIN_VALIDATION=true
    # For custom domain (after reverse proxy setup):
    # - NEXTCLOUD_DATADIR=/mnt/ncdata/ncdata
    # - NEXTCLOUD_TRUSTED_DOMAINS=cloud.yourdomain.com

networks:
  homelab:
    external: true

volumes:
  nextcloud-aio:

Deploy

mkdir -p ~/nextcloud && cd ~/nextcloud
# Save as docker-compose.yml
docker compose up -d

# Check logs
docker compose logs -f nextcloud-aio

Initial Setup via AIO Interface

  1. Open http://your-server:8080
  2. Set a strong master password for AIO management
  3. Enter your domain (or use localhost for LAN only)
  4. AIO will start all containers (Nextcloud, DB, Redis, Collabora)
  5. Access Nextcloud at http://your-server:8080 (or your domain)
  6. Create admin user and complete setup

Alternative: Manual Docker Compose (More Control)

version: '3.8'

services:
  nextcloud:
    image: nextcloud:29-apache
    container_name: nextcloud
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - nextcloud-data:/var/www/html
      - /mnt/data/nextcloud:/var/www/html/data
    environment:
      - MYSQL_HOST=db
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_PASSWORD_FILE=/run/secrets/db_password
      - REDIS_HOST=redis
      - NEXTCLOUD_TRUSTED_DOMAINS=cloud.yourdomain.com
      - OVERWRITE_CLUSTER_URL=https://cloud.yourdomain.com
      - OVERWRITEPROTOCOL=https
    secrets:
      - db_password
    depends_on:
      - db
      - redis

  db:
    image: mariadb:11
    container_name: nextcloud-db
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - nextcloud-db:/var/lib/mysql
    environment:
      - MYSQL_ROOT_PASSWORD_FILE=/run/secrets/db_root_password
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_PASSWORD_FILE=/run/secrets/db_password
    secrets:
      - db_root_password
      - db_password

  redis:
    image: redis:7-alpine
    container_name: nextcloud-redis
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - nextcloud-redis:/data
    command: redis-server --maxmemory 512mb --maxmemory-policy allkeys-lru

networks:
  homelab:
    external: true

volumes:
  nextcloud-data:
  nextcloud-db:
  nextcloud-redis:

secrets:
  db_password:
    file: ./secrets/db_password.txt
  db_root_password:
    file: ./secrets/db_root_password.txt

Post-Install Configuration

Essential Apps to Enable

Apps menu (top right) → Apps → Enable these:

  • Calendar - CalDAV calendar
  • Contacts - CardDAV address book
  • Tasks - CalDAV tasks (syncs with Thunderbird, mobile)
  • Notes - Markdown notes with sync
  • Deck - Kanban boards
  • Forms - Create forms/surveys
  • Talk - Video calls & chat
  • Passwords - Bitwarden-compatible password manager
  • Maps - Photo location mapping
  • Music - Audio player for your library

Configure Collabora Online (Office Suite)

If using AIO: Already included. For manual setup:

  collabora:
    image: collabora/code:latest
    container_name: collabora
    restart: unless-stopped
    networks:
      - homelab
    environment:
      - domain=cloud\\.yourdomain\\.com
      - username=admin
      - password=strongpassword
    ports:
      - "9980:9980"

Then in Nextcloud: Apps → Office → Collabora Online → Set URL to https://collabora.yourdomain.com (via reverse proxy).

Performance Optimization

Redis Caching (Critical)

# In config/config.php:
'memcache.local' => '\\OC\\Memcache\\Redis',
'memcache.distributed' => '\\OC\\Memcache\\Redis',
'memcache.locking' => '\\OC\\Memcache\\Redis',
'redis' => [
    'host' => 'redis',
    'port' => 6379,
],

Preview Generators

# Generate previews for existing files
docker exec -u www-data nextcloud php occ preview:generate-all -vvv

# Schedule daily preview generation
# Add to cron (host): 0 3 * * * docker exec -u www-data nextcloud php occ preview:pre-generate

Background Jobs (Cron)

# On host - run every 5 minutes
*/5 * * * * docker exec -u www-data nextcloud php occ cron

Database Tuning

# MariaDB: add to /etc/mysql/mariadb.conf.d/99-nextcloud.cnf
[mysqld]
innodb_buffer_pool_size = 2G  # 50-70% of RAM
innodb_log_file_size = 512M
innodb_flush_log_at_trx_commit = 2

Client Setup

Desktop Sync Client

  • Windows/macOS/Linux: Official client
  • Selective sync, bandwidth limits, conflict resolution
  • System tray integration, file explorer integration

Mobile Apps

  • iOS: Nextcloud (App Store)
  • Android: Nextcloud (Play Store / F-Droid)
  • Auto-upload photos, offline access, passcode lock

CalDAV/CardDAV Integration

  • Thunderbird: Built-in (Calendar + Address Book)
  • Apple Calendar/Contacts: Add account → CalDAV/CardDAV
  • Android: DAVx⁵ (F-Droid/Play Store) - best sync
  • iOS: Settings → Accounts → Add CalDAV/CardDAV

WebDAV Access

  • Mount as network drive: https://cloud.yourdomain.com/remote.php/dav/files/username/
  • Linux: gvfs-mount davs://cloud.yourdomain.com/remote.php/dav/files/username/
  • Windows: Map network drive
  • rclone: rclone config → type: webdav

Backup Strategy

What to Back Up

  • Database: MariaDB/PostgreSQL dump
  • Data directory: /mnt/data/nextcloud (user files)
  • Config: config/config.php
  • Custom apps/themes: apps/, themes/

Automated Backup Script

#!/bin/bash
# /usr/local/bin/backup-nextcloud.sh
set -euo pipefail

BACKUP_DIR="/mnt/backups/nextcloud"
DATE=$(date +%F_%H-%M)
RETENTION_DAYS=30

mkdir -p "$BACKUP_DIR"

# 1. Put Nextcloud in maintenance mode
docker exec -u www-data nextcloud php occ maintenance:mode --on

# 2. Backup database
docker exec nextcloud-db mariadb-dump -u nextcloud -p"$DB_PASSWORD" nextcloud | gzip > "$BACKUP_DIR/db_$DATE.sql.gz"

# 3. Backup data directory (rsync for efficiency)
rsync -a --delete /mnt/data/nextcloud/ "$BACKUP_DIR/data_$DATE/"

# 4. Backup config
docker cp nextcloud:/var/www/html/config/config.php "$BACKUP_DIR/config_$DATE.php"

# 5. Exit maintenance mode
docker exec -u www-data nextcloud php occ maintenance:mode --off

# 6. Cleanup old backups
find "$BACKUP_DIR" -type f -mtime +$RETENTION_DAYS -delete
find "$BACKUP_DIR" -type d -mtime +$RETENTION_DAYS -empty -delete

echo "Backup completed: $DATE"

Restore Procedure

# 1. Stop Nextcloud
docker compose down

# 2. Restore database
gunzip -c db_2026-01-15_03-00.sql.gz | docker exec -i nextcloud-db mariadb -u nextcloud -p nextcloud

# 3. Restore data directory
rsync -a --delete /mnt/backups/nextcloud/data_2026-01-15_03-00/ /mnt/data/nextcloud/

# 4. Restore config
docker cp config_2026-01-15_03-00.php nextcloud:/var/www/html/config/config.php

# 5. Start and verify
docker compose up -d
docker exec -u www-data nextcloud php occ maintenance:mode --off

Troubleshooting

"Trusted domain" error

# Add to config/config.php:
'trusted_domains' =>
  array (
    0 => 'localhost',
    1 => '192.168.1.100',
    2 => 'cloud.yourdomain.com',
  ),

Slow UI / Timeouts

# Check Redis is working
docker exec nextcloud-redis redis-cli ping
# Should return PONG

# Check PHP memory limit
docker exec nextcloud php -i | grep memory_limit
# Increase in docker-compose: PHP_MEMORY_LIMIT=512M

Collabora not loading

# Check Collabora logs
docker logs collabora

# Verify domain format in env (escape dots):
# domain=cloud\\.yourdomain\\.com

# Check reverse proxy WebSocket support

Files not syncing (client)

# Check Nextcloud logs
docker exec nextcloud tail -f /var/www/html/data/nextcloud.log

# Verify WebDAV endpoint
curl -u user:pass https://cloud.yourdomain.com/remote.php/dav/files/user/

# Check client logs (Windows: %APPDATA%\Nextcloud\logs)

Upgrade issues

# AIO: Use management interface at :8080
# Manual:
docker compose pull
docker compose up -d
docker exec -u www-data nextcloud php occ upgrade
docker exec -u www-data nextcloud php occ maintenance:mode --off

Storage full

# Check usage
docker exec nextcloud php occ files:scan --all
docker exec nextcloud php occ files:cleanup

# Check versions/trashbin
docker exec nextcloud php occ versions:cleanup
docker exec nextcloud php occ trashbin:cleanup --all-users
