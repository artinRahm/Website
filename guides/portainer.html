Portainer

Visual web UI for managing Docker containers, images, networks, and volumes. Makes container management easy with stack deployment, resource monitoring, and access control.

Beginner ~15 min read Updated 2026

Why Portainer?

Web-Based GUI

Manage everything from a browser. No CLI required for daily operations. Great for visual learners.

Stack Deployment (Compose)

Deploy multi-container apps with Docker Compose files. Edit, version, and redeploy stacks easily.

Resource Monitoring

Real-time CPU, memory, network, and disk usage per container. Historical graphs for capacity planning.

Access Control (RBAC)

Teams, roles, resource pools. Limit who can deploy, view logs, exec into containers. SSO via OIDC/LDAP.

Multi-Environment

Manage local Docker, remote Docker, Kubernetes, ACI, Nomad from one UI. Edge agents for remote nodes.

App Templates

One-click deploy for 100+ popular apps. Create custom templates for your standard stacks.

Docker Deployment

Docker Compose (Standalone)

version: '3.8'

services:
  portainer:
    image: portainer/portainer-ce:2.21
    container_name: portainer
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - portainer-data:/data
      - /var/run/docker.sock:/var/run/docker.sock
    ports:
      - "9000:9000"   # HTTP
      - "9443:9443"   # HTTPS
    environment:
      - TZ=America/New_York

networks:
  homelab:
    external: true

volumes:
  portainer-data:

Deploy

mkdir -p ~/portainer && cd ~/portainer
# Save as docker-compose.yml
docker compose up -d

# Check logs
docker compose logs -f portainer

Initial Setup

  1. Open https://your-server:9443 (accept self-signed cert)
  2. Create admin user (username/password)
  3. Select "Get Started" → "Docker" → "Local" environment
  4. Click "Connect" - Portainer detects local Docker

Core Features Walkthrough

Home Dashboard

Overview of all environments, container counts, resource usage, and quick actions.

Containers

  • List all containers with status, image, ports, networks
  • Start/stop/restart/kill/remove with one click
  • View logs (with search/filter), inspect JSON, stats
  • Exec into container (interactive terminal in browser)
  • Attach to running container
  • Duplicate/edit container (creates new with same config)

Images

  • Pull, import, export, remove images
  • Tag images, view layers, vulnerability scan (with Trivy)
  • Prune unused images to reclaim space

Stacks (Docker Compose)

The most powerful feature for home lab management.

# Example stack - Jellyfin with hardware transcoding
version: '3.8'
services:
  jellyfin:
    image: jellyfin/jellyfin:10.10.7
    container_name: jellyfin
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - jellyfin-config:/config
      - jellyfin-metadata:/data
      - /mnt/media:/media:ro
    ports:
      - "8096:8096"
    devices:
      - /dev/dri:/dev/dri
    environment:
      - TZ=America/New_York
    deploy:
      resources:
        limits:
          memory: 2G

networks:
  homelab:
    external: true

volumes:
  jellyfin-config:
  jellyfin-metadata:
  1. Stacks → + Add stack
  2. Name: "jellyfin", paste Compose YAML
  3. Deploy the stack
  4. Portainer pulls images, creates network/volumes, starts containers
  5. Update: Edit stack → Redeploy (pulls new images, recreates containers)

Networks & Volumes

  • Visual network topology
  • Create/manage bridge, overlay, macvlan networks
  • Volume management: create, browse, backup, remove
  • Bind mount management

Environments

Add remote Docker hosts, Kubernetes clusters, or edge agents for managing multiple nodes from one Portainer instance.

Advanced Configuration

Reverse Proxy with SSL

Using Nginx Proxy Manager (see Reverse Proxy Guide):

  1. Add proxy host: portainer.yourdomain.com
  2. Forward to: portainer:9000
  3. Enable WebSocket support
  4. SSL: Let's Encrypt, Force SSL, HSTS

Backup Portainer Data

#!/bin/bash
# Backup Portainer config (includes users, settings, stacks)
DATE=$(date +%F)
docker run --rm \
  -v portainer-data:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/portainer-backup-$DATE.tar.gz -C /data .

# Restore:
docker run --rm \
  -v portainer-data:/data \
  -v $(pwd):/backup \
  alpine tar xzf /backup/portainer-backup-2026-01-15.tar.gz -C /data

Enable Authentication (OIDC/LDAP)

Settings → Authentication → Add OIDC provider (Authentik, Keycloak, etc.) or LDAP server.

Resource Limits & Reservations

In stack editor, add deploy resources:

deploy:
  resources:
    limits:
      cpus: '2'
      memory: 2G
    reservations:
      cpus: '0.5'
      memory: 512M

Troubleshooting

Cannot connect to Docker socket

# Check socket permissions
ls -la /var/run/docker.sock
# Should be root:docker

# Add portainer user to docker group (if not root in container)
# Or run container as root (default)

Stack deploy fails

# Check stack logs in Portainer UI
# Or via CLI:
docker compose -f /var/lib/portainer/stacks/1/docker-compose.yml up -d

# Common issues:
# - Port conflicts
# - Volume permissions
# - Missing networks (create external first)

Forgot admin password

# Reset admin password
docker run --rm \
  -v portainer-data:/data \
  portainer/portainer-ce:2.21 \
  --admin-password='$2a$12$newpasswordhash' \
  --reset-password

# Or delete /data/portainer.db and restart (loses all settings)

Edge agent won't connect

# Check edge agent logs
docker logs portainer-edge-agent

# Verify environment variables:
# EDGE_KEY, EDGE_ID, CAP_PORTAINER_URL
