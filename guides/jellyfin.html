Jellyfin Media Server

Complete guide to setting up Jellyfin - the free, open-source media server. Hardware transcoding, metadata management, remote access, and client apps.

Beginner ~30 min read Updated 2026

Why Jellyfin?

Free & Open Source

No subscriptions, no premium features locked behind paywall. MIT licensed. Community-driven development.

Privacy First

Your media, your server, your data. No telemetry, no tracking, no account required. Runs entirely on your hardware.

Hardware Transcoding

Intel Quick Sync, NVIDIA NVENC, AMD VCE/VCN, Apple VideoToolbox. Efficient 4K→1080p transcoding on modest hardware.

Live TV & DVR

HDHomeRun, IPTV, M3U playlists. Record, schedule, series recordings. Electronic program guide (EPG).

Multi-User & Parental Controls

Multiple users with individual libraries, watch history, preferences. Content ratings, PIN protection for kids.

Great Client Ecosystem

Official apps for iOS, Android, Android TV, Fire TV, Roku, Web, desktop. Third-party: Infuse, Swiftfin, Findroid.

Docker Deployment

Basic Docker Compose

version: '3.8'

services:
  jellyfin:
    image: jellyfin/jellyfin:10.10.7
    container_name: jellyfin
    restart: unless-stopped
    networks:
      - homelab
    volumes:
      - jellyfin-config:/config
      - jellyfin-metadata:/data
      - /mnt/media:/media:ro
    ports:
      - "8096:8096"
      - "8920:8920"  # HTTPS (optional)
      - "1900:1900/udp"  # DLNA
    environment:
      - TZ=America/New_York
      - JELLYFIN_PublishedServerUrl=https://jellyfin.yourdomain.com
    # Uncomment for hardware transcoding (see next section)
    # devices:
    #   - /dev/dri:/dev/dri
    healthcheck:
      test: ["CMD-SHELL", "curl -f http://localhost:8096/health || exit 1"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 40s

networks:
  homelab:
    external: true

volumes:
  jellyfin-config:
  jellyfin-metadata:

Deploy

mkdir -p ~/jellyfin && cd ~/jellyfin
# Save as docker-compose.yml
docker compose up -d

# Check logs
docker compose logs -f jellyfin

Initial Setup Wizard

  1. Open http://your-server:8096
  2. Create admin user (username/password)
  3. Add media libraries (Movies, TV Shows, Music, Photos)
  4. Configure metadata providers (TheMovieDB, TheTVDB, MusicBrainz)
  5. Set up remote access (skip - we'll use reverse proxy)

Hardware Transcoding (Intel Quick Sync)

Host Requirements

# Check if iGPU is available
ls -la /dev/dri/
# Should show: renderD128, card0

# Check Quick Sync support
vainfo
# Look for: VAProfileH264Main, VAProfileHEVCMain, etc.

# Install Intel media drivers (Ubuntu)
sudo apt install -y intel-media-va-driver-non-free vainfo

Docker Compose with Hardware Transcoding

services:
  jellyfin:
    image: jellyfin/jellyfin:10.10.7
    # ... other config ...
    devices:
      - /dev/dri:/dev/dri
    # Optional: limit GPU memory
    # deploy:
    #   resources:
    #     reservations:
    #       devices:
    #         - driver: "intel.com/gpu"
    #           count: 1
    #           capabilities: ["gpu"]

Jellyfin Transcoding Settings

In Jellyfin Dashboard → Playback → Transcoding:

  • Enable hardware acceleration: ✅ On
  • Hardware acceleration device: /dev/dri/renderD128
  • Enable hardware encoding: ✅ On
  • Encoder preset: balanced (or speed for older iGPU)
  • Enable VA-API: ✅ On
  • Enable Intel Quick Sync: ✅ On
  • Allow HEVC encoding: ✅ On (if iGPU supports)
  • Fallback to software: ✅ On

Verify Hardware Transcoding Works

  1. Play a video that requires transcoding (HEVC → H.264, or 4K → 1080p)
  2. In Jellyfin Dashboard → Dashboard → Active Sessions
  3. Look for VideoCodec: hevc → h264 (hardware) or similar
  4. On host: intel_gpu_top should show GPU usage

NVIDIA NVENC (Alternative)

services:
  jellyfin:
    image: jellyfin/jellyfin:10.10.7
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu, compute, video]
    environment:
      - NVIDIA_VISIBLE_DEVICES=all
      - NVIDIA_DRIVER_CAPABILITIES=compute,video,utility

Library Configuration

  1. Dashboard → Libraries → +
  2. Content Type: Movies / TV Shows / Music / Photos / Books
  3. Display Name: "Movies"
  4. Folders: /media/Movies
  5. Metadata tab:
    • Metadata fetcher: TheMovieDB (movies), TheTVDB (TV), MusicBrainz (music)
    • Enable: "Download images", "Save local metadata"
    • Preferred language: English (or your preference)
    • Country: US (for correct release dates/ratings)
  6. Scan on library creation + Enable real-time monitoring

Metadata Tips

  • Use Tiny Media Manager or FileBot to pre-fetch metadata/nfo files
  • Name files exactly: Movie Name (Year).ext and Show Name - S01E01 - Title.ext
  • Embed subtitles in MKV or use .srt sidecar with same name
  • For collections: create collections.nfo or use Jellyfin's collection manager

Remote Access

Option 1: Tailscale (Easiest)

# On Jellyfin server
sudo tailscale up --advertise-routes=192.168.1.0/24

# On client devices: install Tailscale app, sign in
# Access: http://jellyfin-hostname:8096 or http://100.x.y.z:8096

Option 2: Reverse Proxy + SSL (Public Access)

Using Nginx Proxy Manager (see Reverse Proxy Guide):

  1. Add proxy host: jellyfin.yourdomain.com
  2. Forward to: jellyfin:8096
  3. Enable WebSocket support (required for sync/playback)
  4. SSL: Let's Encrypt cert, Force SSL, HSTS
  5. In Jellyfin: Dashboard → Networking → Published Server URL = https://jellyfin.yourdomain.com

Jellyfin Networking Settings

# In docker-compose.yml, add:
environment:
  - JELLYFIN_PublishedServerUrl=https://jellyfin.yourdomain.com
  # If using Tailscale only:
  # - JELLYFIN_PublishedServerUrl=http://jellyfin-tailnet-name:8096

Clients: Remote Access Setup

  • Mobile apps: Enter server URL manually or auto-discover via Tailscale
  • Android TV / Fire TV: Use "Enter server URL" option
  • Infuse (iOS): Add Jellyfin share via URL
  • Web: Just open https://jellyfin.yourdomain.com

Client Apps

Official Apps

  • Web: Any browser at :8096/web
  • Android: Play Store / F-Droid
  • iOS/iPadOS: App Store
  • Android TV: Play Store (NVIDIA Shield, Chromecast, etc.)
  • Fire TV: Amazon Appstore
  • Roku: Channel Store (beta)
  • Desktop: Windows/Mac/Linux (Electron)

Third-Party (Often Better)

  • Infuse (iOS/tvOS/macOS): Best playback, paid but worth it
  • Swiftfin (iOS): Native SwiftUI, free, open source
  • Findroid (Android): Material You, feature-rich
  • Jellyfin Media Player (Desktop): MPV-based, better codec support
  • Jellyfin for Kodi: Full Kodi integration

Offline Sync

Download media for offline viewing (mobile apps):

  • Enable in Jellyfin: Dashboard → Users → Enable sync
  • Set max sync bitrate (e.g., 20 Mbps for 1080p)
  • On mobile app: long-press item → "Download" or "Sync"
  • Manage in Dashboard → Sync Jobs

Optimization & Tips

Performance Tuning

Metadata on SSD

Store /config and /data on SSD/NVMe. HDD for media only. Massive UI speedup.

Chapter Images / Preview Thumbnails

Generate in Dashboard → Scheduled Tasks → "Generate chapter images" + "Generate video preview thumbnails". Run weekly.

Transcode Cache

Set transcode cache to RAM disk: --mount=type=tmpfs,destination=/transcodes in Docker.

Database Maintenance

Run VACUUM on SQLite DB monthly. Dashboard → Scheduled Tasks → "Database maintenance".

Scan Schedules

Set library scans to run at night. Real-time monitoring + daily deep scan.

Image Optimization

Dashboard → Libraries → "Optimize images" - creates smaller versions for thumbnails.

Quality Profiles

Dashboard → Playback → Quality Profiles - Create profiles for different scenarios:

Home (Direct Play):      Max bitrate: 100 Mbps, Allow direct play: ✅
Remote (WiFi):            Max bitrate: 30 Mbps,  Allow direct play: ✅
Remote (Cellular):        Max bitrate: 8 Mbps,   Allow direct play: ❌
Remote (Slow):            Max bitrate: 3 Mbps,   Allow direct play: ❌

Troubleshooting

Hardware transcoding not working

# Verify device passthrough
docker exec jellyfin ls -la /dev/dri/

# Check permissions
docker exec jellyfin ffmpeg -init_hw_device vaapi=foo:/dev/dri/renderD128 -f lavfi -i nullsrc -c:v h264_vaapi -f null -

# Check Jellyfin logs for "vaapi" or "quick_sync"

Buffering / Playback issues

# Check network path
# Client → Reverse Proxy → Jellyfin
# Try direct LAN IP to isolate proxy

# Enable "Direct Play" in client settings
# Lower remote quality profile

Metadata not fetching

# Check internet access from container
docker exec jellyfin curl -I https://api.themoviedb.org

# Verify API keys in Dashboard → Metadata
# TheMovieDB: Free API key required
# TheTVDB: Paid API key now required

DLNA not showing

# Ensure ports exposed
ports:
  - "1900:1900/udp"
  - "7359:7359"  # SSDP alternate

# Check firewall
sudo ufw allow 1900/udp

4K HDR tone mapping issues

Intel Quick Sync supports HDR→SDR tone mapping (11th gen+). In transcoding settings, enable "Tone mapping" and set target: BT.709 (SDR).

Subtitle issues

PGS (Blu-ray) subtitles require burn-in. Enable "Burn subtitles" in playback settings or use SRT/VTT instead.
